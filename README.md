#ChatGPT KSU

ChatGPT KSU 是基于 KernelSU 原版进行二次定制美化的项目。仅对 KernelSU 管理器 App 进行界面重构，采用 ChatGPT 极简黑白UI风格重绘视觉与交互，内核底层代码完全保持原样，无篡改、无额外植入程序，原生 Root 与模块相关能力与原版保持一致。
 
本项目属于爱好者非商用UI美化二次创作，内核底层相关知识产权归属 KernelSU 官方开发团队，项目遵循对应的开源协议。
 
KernelSU 官方网站：https://kernelsu.org/zh_CN/
KernelSU 官方 GitHub：https://github.com/tiann/KernelSU

✨ 项目特色
 
1. 全局UI采用 ChatGPT 经典极简黑白设计，界面清爽低干扰；
​
2. 重构页面布局、按钮、弹窗、卡片样式，全部原有功能入口保留，操作逻辑不变，原版用户可以无缝上手；
​
3. 优化日志、模块列表、权限管理页面排版，适配高分、高刷屏设备；
​
4. 完整保留原版所有设置项、日志输出、模块管理、权限管控规则，功能100%对齐原版。
 
兼容信息
 
- 支持平台：Android、WSA、ChromeOS、容器Android环境
​
- 支持架构： arm64-v8a 、 x86_64 
 
使用方式
 
安装、刷入、编译的操作流程与原版 KernelSU 完全一致，原版的模块、教程都可以直接使用。
 
- 漏洞上报：安全问题参考 KernelSU 仓库  SECURITY.md
